## DRF Приложение - Electronics Store

## Описание
Electronics Store — это онлайн-платформа для ведения деловых взаимоотношений между различными фирмами, занимающимися продажей электротехнического и цифрового оборудования. Здесь можно разместить информацию о звене сети продажи электроники, то есть поставщике или дистрибьюторе (название, тип, контакты, товары, поставщика у которого данный дистрибьютор покупает и долг перед соответствующим поставщиком).

## Установка
git clone git@github.com:KovkovDS/Electronics_store.git

## Установка зависимостей
Используй Poetry для установки пакетов и активации виртуальной среды:

poetry shell (или "poetry env activate" для версий выше Python 3.12)

poetry install

## Конфигурация окружения
Создай файл .env и заполни его необходимыми параметрами:

SECRET_KEY=your_secret_key_here

Настройки базы данных:

NAME=

USER=

PASSWORD=

HOST=

PORT=

## Первоначальная настройка базы данных
Создай и мигрируй схемы базы данных:

python manage.py makemigrations
python manage.py migrate

## Запуск проекта
Для запуска локального сервера используй команду:

python manage.py runserver
Платформа будет доступна по адресу http://127.0.0.1:8000/ или http://localhost:8000/

## Тестирование
Для запуска тестов выполните команду:

python manage.py test

Также можно посмотреть процент покрытия тестами основных приложений платформы:

pytest --cov=electronics_store -report

pytest --cov=users -report

## Создание администратора
Создать суперпользователя можно специальной командой проекта:

python manage.py csu

## Возможности платформы
- Создание звена сети продажи электроники с контактами звена и реализуемыми товарами.
- Редактирование звена сети продаж электроники (кроме поля долг).
- Просмотр списка звеньев и информации о конкретном звене сети продаж электроники.
- Удаление звена сети продаж электроники.
- Так же есть фильтрация по стране.
- Создание контакта.
- Редактирование контакта.
- Просмотр списка контактов и информации о конкретном экземпляре контактов.
- Удаление контакта.
- Создание продукта.
- Редактирование продукта.
- Просмотр списка продуктов и информации о конкретном продукте.
- Удаление продукта.
- В административной панели сделан вывод созданных всех объектов. 
- Также в административной панели для звеньев сети продажи электроники выведена подробная информация. У каждого объекта сть ссылка на поставщика, связанные с объектом контакты и продукты, фильтр по названию города.
- Также добавлен "admin action" (в виде кнопки), очищающий задолженность перед поставщиком у выбранных объектов.

## Требования к окружению
Рекомендуемая версия Python: 3.12 и выше
Рекомендуемая версия Django: 5.x

## Основные зависимости:
Django: фреймворк для построения веб-приложений.
Django Rest Framework
Psycopg2: драйвер для подключения к базе данных PostgreSQL.
Pillow: библиотека для работы с изображениями.
pytest и coverage: инструмент для автоматизированного тестирования и покрытия тестами.
